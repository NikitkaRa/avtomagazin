# Автомагазин — локальная демка

Два окна браузера. Без серверов и без Tailscale.

## Запуск

```bash
docker compose up -d
./scripts/start-dev.sh
```

- Житель: http://127.0.0.1:5201
- Персонал: http://127.0.0.1:5200

## Сценарий для показа (2 минуты)

1. Открой **жителя** — карта с Гродно и Пуховичами. Чип **Озеричино** или кнопка «Ближайшая остановка» (дома ~53.577, 27.747).
2. Открой **персонал** → «Водитель Озеричино» → **Демо-маршрут**.
3. Вернись к жителю: фургон 5678 CD-4 кружит у Озеричино, ETA обновляется.
4. Добавь Озеричино в избранное. Водитель жмёт «На месте» — пуш только избранным.
5. Войди как оператор — карта обоих рейсов, отметки жителей, визиты, лог пушей.
6. Офлайн жителя: DevTools → Offline → обнови страницу. Расписание остаётся; куски OSM, которые уже открывали, тоже (кэш `/tiles`).

GPS с телефона в приложении предусмотрен («Транслировать GPS»). По HTTP браузер телефона часто его режет — для комиссии достаточно демо-маршрута. На ноутбуке через localhost GPS обычно работает.

Карта: OSM без ключа, тайлы проксируются через приложение и копятся в Cache API. Яндекс — если есть ключ `Maps:YandexApiKey`; его тайлы по оферте так не копим. Если кусков ещё не было — схема точек.

## Кто чем пользуется

| Кто | Приложение | Что делает |
|-----|------------|------------|
| Житель | `:5201` | Карта / схема, кто едет, во сколько, подписка. Офлайн — последний график |
| Водитель / продавец | `:5200` (роль driver) | Транслирует точку, видит следующую остановку |
| Оператор райпо | `:5200` (роль operator) | Карта всех машин, маршруты, парк |

Это не две разные кодовые базы персонала: один вход, вид от роли.

## Черновик обращения

В Беларуси анонсирован сервис «Автомагазин» (Минсвязи, пилот Гродно к концу 2027). Рабочий прототип уже есть: житель видит, куда и когда едет автолавка, **даже без интернета** — по последнему расписанию; водитель/продавец может транслировать геолокацию с телефона, без бортового GPS; оператор видит покрытие деревень.

Исходники открытые, стек .NET / Postgres / RabbitMQ, без проприетарных лицензий. Готов показать демо локально и отдать код как основу, либо подключиться как самозанятый на пилот.
