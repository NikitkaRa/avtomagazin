# Автомагазин — локальная демка

Админка в браузере. Житель — в ResidentApp (эмулятор или телефон).

## Запуск

```bash
docker compose up -d
./scripts/start-dev.sh
```

- Персонал: http://127.0.0.1:5200 — вход email/пароль
- Android: `./scripts/run-android.sh resident` и `./scripts/run-android.sh staff`

## Сценарий для показа (2 минуты)

1. Открой **жителя** (ResidentApp) — карта с Гродно и Пуховичами. Чип **Озеричино** или кнопка «Ближайшая остановка» (дома ~53.577, 27.747).
2. Открой **персонал** → `seller@demo.by` / `demo` (водитель Озеричино) → **Демо-маршрут**.
3. Вернись к жителю: фургон 5678 CD-4 кружит у Озеричино, точка на карте обновляется.
4. Войди как житель (`resident@demo.by` / `demo` или регистрация) и добавь Озеричино в избранное. Водитель жмёт «На месте» — пуш только подписанным.
5. Войди как диспетчер (`operator@demo.by` / `demo`) — карта обоих рейсов, отметки жителей, визиты, лог пушей и **сколько человек подписано на пункт**.
6. Войди как админ (`admin@demo.by` / `demo`) — вкладка **Люди**: заявки водителя/диспетчера из StaffApp.

GPS с телефона в приложении предусмотрен («Транслировать GPS»). Для комиссии достаточно демо-маршрута.

Карта: OSM без ключа. Яндекс — если есть ключ `Maps:YandexApiKey`. Если кусков ещё не было — схема точек.

## Кто чем пользуется

| Кто | Приложение | Что делает |
|-----|------------|------------|
| Житель | ResidentApp | Регистрация сразу, карта, подписка |
| Водитель | StaffApp или `:5200` | Ведёт автолавку, продаёт, точка и «на месте» |
| Диспетчер | `:5200` (и StaffApp) | Карта парка, маршруты, подписки |
| Админ | `:5200` | Подтверждает персонал |

На телефоне житель и персонал — разные приложения. Роль берётся из того, откуда регались, а не выбирается руками на бэкенде.

## Черновик обращения

В Беларуси анонсирован сервис «Автомагазин» (Минсвязи, пилот Гродно к концу 2027). Рабочий прототип уже есть: житель видит, куда и когда едет автолавка, **даже без интернета** — по последнему расписанию; водитель-продавец может транслировать геолокацию с телефона, без бортового GPS; диспетчер видит покрытие деревень.

Исходники открытые, стек .NET / Postgres / RabbitMQ, без проприетарных лицензий. Готов показать демо локально и отдать код как основу, либо подключиться как самозанятый на пилот.
